隱私政策

適用範圍

本政策說明「國立新化高工資訊科GDS-1102B」應用程式如何處理本機示波器資料。開發與維護單位為國立新化高工資訊科。

本機資料處理

使用 USB 實機模式時，程式會列出本機可用的序列埠名稱。只有使用者明確選取並連線的埠會被開啟；程式先查詢儀器識別，確認為 GDS-1102B 後才進行後續讀取或控制。

程式於本次工作階段處理儀器型號、序號、韌體版本、設定、擷取狀態、波形取樣、讀取時間及由波形計算的數值。這些資料用於本機顯示、操作回饋與錯誤診斷。離線模擬模式使用程式產生的合成資料，不讀取示波器。

目前版本沒有提供自動保存、檔案匯出或雲端同步儀器資料的功能。正常斷線或切換來源會清除目前顯示的來源資料；結束程式會結束本次工作階段。

傳送、帳號與追蹤

本應用程式自訂功能不主動將上述儀器識別、設定、波形或計算數值傳送給開發單位或其他線上服務。程式未設使用者帳號、廣告、追蹤或自訂使用分析上傳功能；核心觀察與模擬功能可離線使用。

這項說明限於本應用程式自行實作的資料流程。Windows、Microsoft Store、Microsoft 執行階段與系統診斷可能依各自條款、隱私聲明及裝置設定處理資料；本政策不代替這些服務或元件的說明，也不宣稱它們完全不會收集診斷資訊。

權限

本程式以桌面應用程式方式執行，宣告 runFullTrust 以使用桌面 API 與 USB CDC／虛擬 COM 連線。自訂功能沒有要求相機、麥克風、位置、聯絡人或使用者檔案存取；套件依賴項目存在於安裝內容中，不代表程式會啟用其所有功能。

使用者提供的支援資料

目前程式未內建錯誤報告自動上傳。若使用者自行透過下列 GitHub Issues 支援管道提供截圖、錯誤訊息或測試資料，資料範圍由使用者提供的內容決定。Issues 是公開頁面，內容會由 GitHub 依其服務條款與隱私聲明儲存及提供；維護者僅依回覆支援與改善程式的目的處理。請勿張貼個人資訊、儀器序號或機密量測內容。

更新與聯絡

如後續版本加入儀器資料保存、匯出、帳號、網路傳送或新的資料處理方式，將同步更新本政策及商店相關說明。
