# 國立新化高工資訊科GDS-1102B

本資料夾提供應用程式 **2.0.0** 的公開隱私政策與支援頁。政策更新日期為 **2026-10-19**，開發與維護單位為國立新化高工資訊科。

- `index.html`：繁體中文隱私政策與支援管道，樣式全部內嵌，可直接以瀏覽器開啟。
- `.nojekyll`：供靜態頁面直接發布使用。
- `README.md`：本頁說明。

政策內容與應用程式的隱私政策一致，涵蓋本機 USB／離線模擬資料處理、使用者透過 Windows 儲存選擇器保存 PNG 波形圖、圖檔內容與保留方式、傳送與追蹤、權限、使用者自行提供的公開支援資料，以及後續更新方式。PNG 不由應用程式自動上傳或雲端同步。頁面沒有登入、分析工具、追蹤程式、外部字型或外部資產。

支援與隱私問題：[GDS-1102B 支援 Issues](https://github.com/chiangyih/gds1102b-privacy/issues)。Issues 為公開頁面，請勿張貼個人資訊、儀器序號或機密量測內容。

政策公開來源：[gds1102b-privacy](https://github.com/chiangyih/gds1102b-privacy)。

公開網站只需此資料夾內的三個檔案；不需要應用程式原始碼、建置產物、儀器記錄或本機驗證資料。
